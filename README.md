# FlashCompressor

Free, privacy-first file compression in the browser.

## Features
- Image compression with a visible target-size control
- Adjustable image dimensions
- ZIP mode for any file type, including PDFs, videos and documents
- GZIP mode for text and code
- Multiple files and drag-and-drop
- Download results directly
- No account and no paid tier
- Files are processed locally in the browser

## Note
ZIP mode bundles any file type but cannot guarantee a smaller result for files that are already compressed. True PDF/video compression requires format-specific processing and is not faked by this app.
