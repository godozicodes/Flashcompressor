# FlashCompressor

Free browser-based file compression by godozicodes.

## Features
- Image compression with target size, quality and dimensions
- PDF rebuild compression for scanned/image-heavy PDFs
- ZIP mode for any file type
- GZIP for text and source files
- Multiple files and drag-and-drop
- No sign-up, no paywall
- Browser-based processing for supported formats

## Privacy
Files are processed in the browser. FlashCompressor does not require a server upload for supported compression.

## Important
ZIP cannot guarantee a smaller result for already-compressed files such as many MP4, JPEG and ZIP files. PDF rebuild compression is best for scanned/image-heavy PDFs and may not reduce every PDF.
